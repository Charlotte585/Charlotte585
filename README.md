## 🚀 Featured Project

### [Agentic Data Modeling Lifecycle](https://github.com/Charlotte585/agentic-data-modeling-lifecycle)

An advertising data modeling project that connects business requirements, Python source validation, and dbt transformations.

**Implemented**

- Synthetic source fixtures, Python validation, and raw ingestion.
- Three staging models for ad events, identity history, and ad metadata.
- Event-time identity resolution with history-integrity and event uniqueness tests.

**Design focus:** matching events to the identity valid at the time of interaction, preserving event grain, and distinguishing anonymous visitors from unmatched identities.

**Next:** ad metadata enrichment, sessionization, and reusable facts and dimensions. Agent workflows and downstream ML are part of the longer-term roadmap.
